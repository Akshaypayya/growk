A premier GCC-focused FinTech and wealth-building mobile application built with Flutter. **Growk** democratizes financial growth across Saudi Arabia and the UAE by enabling digital gold investments, goal-driven automated micro-savings, and smart wallet management backed by national single sign-on authentication (**Nafath** & **UAE PASS**).

---

## 🌟 Key Features

- **🪙 Digital Gold Investment**: Buy and sell 24K digital gold instantly by monetary value (SAR) or physical weight in grams (`buy_by_amount`, `buy_by_weight`, `instant_gold`).
- **🎯 Goal-Based Micro-Savings**: Set up personalized financial milestones for weddings, education, travel, or custom targets with automated savings tracking.
- **🔑 Sovereign Digital Identity**: Government-grade onboarding and KYC verification integrated with **Nafath** (Saudi National Single Sign-On) and **UAE PASS** (UAE Digital Identity).
- **💳 Secure Digital Wallet**: Multi-asset digital wallet infrastructure (`bankbox-wallet`) with real-time balance tracking, statements, and transaction histories.
- **🌓 Adaptive Dual Themes**: Seamlessly designed for both Dark Mode and Light Mode with tailored high-contrast financial data visualization.
- **🌐 Bilingual Arabic & English Support**: Native right-to-left (RTL) Arabic and left-to-right (LTR) English interface switching.
- **🔒 Biometric Protection**: Fast, secure fingerprint / biometric authentication for authorizing high-value asset purchases and withdrawals.
- **🎁 Rewards & Referrals Engine**: Earn bonus perks and referral cashbacks on completed milestone goals.

## 📲 Installation

To install the release build on an Android device:

1. Download the [`app-release.apk`](app-release.apk) file from this repository or the Releases section.
2. Enable **Install from Unknown Sources** in your Android device settings if prompted.
3. Open the APK file on your device and tap **Install**.
4. Launch **Growk** and start growing your wealth!

Alternatively, install via ADB:
```bash
adb install -r app-release.apk
```
